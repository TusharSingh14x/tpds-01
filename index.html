Git & GitHub Commands

Reference list of all terminal commands executed to satisfy Practical 1 repository creation, branching, merging, and deployment.

#GIT SPECS
01. REPO & MAIN GIT INIT
# Initialize repository
$ git init
# Add remote GitHub repo
$ git remote add origin https://github.com/TusharSingh14x/tpds-01.git
# Stage files & commit
$ git add .
$ git commit -m "feat: initial commit"
# Set main branch and push
$ git branch -M main
$ git push -u origin main
02. FEATURE BRANCHING PR & MERGE
# Create and switch to feature branch
$ git checkout -b feature/task-manager
# Add feature files & commit
$ git add .
$ git commit -m "feat: add task manager"
# Push branch to GitHub for Pull Request
$ git push origin feature/task-manager
# Merge locally or via GitHub PR
$ git checkout main
$ git merge feature/task-manager
$ git push origin main
